# data/

Raw USDA FoodData Central downloads land here (gitignored). `npm run fdc:import`
reads the zips in this folder:

- `FoodData_Central_foundation_food_csv_*.zip`
- `FoodData_Central_sr_legacy_food_csv_*.zip`
- `FoodData_Central_branded_food_csv_*.zip` (~430 MB)

Download page: https://fdc.nal.usda.gov/download-datasets/
